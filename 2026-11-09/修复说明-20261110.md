## BUG-01 / BUG-02 / BUG-03：附件（TXT / 文转音 / 视频）显示“已发送”但接收端没有

三条是同一根因，一起修。

**根因**：Zalo 接入层 `session-manager.mjs` 的 `send()` 在平台没有回消息 ID 时，用本地 `transaction`（UUID）兜底当作 `resultId`，并照样把记录置为 `state=sent`。界面据此显示「已发送」，但平台侧其实没有确认这条消息，接收端自然收不到。文本消息因为 `result.message.msgId` 通常存在，所以不受影响，这也解释了“后续文字正常到达”。

**改动**（`frontend-user/scripts/zalo/session-manager.mjs`）：

- 发送结果必须带平台消息 ID：附件消息取 `result.attachment[0].msgId`，原生语音（`sendVoice` / `uploadAttachment` 回执）取 `result.msgId` 或 `result.message.msgId`，纯文本取 `result.message.msgId`；
- 取不到 ID 直接抛 `502「平台未确认消息发送」`，记录落 `state=unknown`，界面显示“发送结果未知，请检查会话”，不再显示“已发送”；
- 同一 `transaction` 的 `unknown` 记录不允许自动重试（`409`），避免重复投递；
- 文转音先 `uploadAttachment` 拿 `fileUrl`，校验必须是 `https` 且不带账号密码，再 `sendVoice({voiceUrl})`；上传没给地址直接报错，不会退化成静默成功。

**说明**：这次修的是“不能把未确认当成功”。真实双端送达仍受 Zalo 账号与网络环境影响，需要在测试环境按下面的步骤实发复验。

## BUG-04：聊天气泡的图片/视频预览按钮是禁用的

**根因**：Zalo 会话气泡没有接工作台共用的预览组件，图片/视频气泡只渲染缩略图，“预览图片/预览视频”按钮保持 `disabled`；只有右侧媒体面板能看大图。

**改动**（`frontend-user/src/pages/sessions/ZaloMessage.tsx`）：

- 接入 `MediaLightbox`，气泡上的图片/视频可点开全屏预览，支持下载；
- 预览失败显示错误文案，不再静默。

## BUG-05：“管理账号”展开空白菜单

**根因**：账号卡的管理菜单只有在传入「刷新账号状态」动作时才渲染菜单项。Zalo 工作台没有传这个回调，菜单容器照样弹出，于是只剩一条空白条目。

**改动**：

- `frontend-user/src/components/sessions/PlatformAccountRow.tsx`：Zalo 渠道的菜单项文案改为「刷新账号状态」（其它渠道仍是「强制刷新」）；
- `frontend-user/src/pages/sessions/ZaloWorkbench.tsx`：补上 `onRefreshAccount`，点击后重新拉取账号、Java 绑定和当前会话列表，失败时 `run()` 会把错误显示在页面上。

## Facebook OBS-01：空账号分组仍显示上一个账号的设置

**根因**：分组筛选后账号列表为空时，中栏仍保留上一个选中账号的内容，左侧只写“这个分组里还没有本平台的账号”，没有提示右侧看的是组外账号。

**改动**（`frontend-user/src/components/sessions/PlatformAccountBar.tsx`）：当“分组里没有账号、但右侧仍显示上一个账号”时，提示改为「此分组暂无账号，右侧仍显示上一个账号」，让当前上下文明确。
